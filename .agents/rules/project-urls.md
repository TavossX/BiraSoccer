# URLs e Domínios Oficiais do Projeto BiraSoccer

## URLs de Produção e Ambientes

- **URL Oficial de Produção (Frontend Vercel)**: `https://birasoccer.vercel.app/`
- **Dashboard / Mural de Troféus**: `https://birasoccer.vercel.app/dashboard`

## Regra de Utilização
Sempre que for gerar templates de e-mail, links de convite, webhooks, callbacks OAuth ou redirecionamentos para o frontend na web, utilize **`https://birasoccer.vercel.app/`** como a URL base padrão.
